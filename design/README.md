# Исходники макета

Каждый файл `*.dc.html` — один артборд макета из Claude Design. Сам макет с кликабельными состояниями: https://claude.ai/code/artifact/8f1ae0b7-2689-4d65-8e33-203b4bd15a74

## Как читать файлы

- Вёрстка лежит внутри `<x-dc> … </x-dc>`. Это обычный HTML с инлайн-стилями: размеры, отступы, цвета и тексты — точные значения из макета.
- `data-name="…"` — имя компонента (`Header`, `ServiceHero`, `PackageCard`, `CallButton`…). Используйте эти имена для компонентов в коде.
- `{{name}}` — подстановка значения из логики внизу файла (`<script type="text/x-dc">`, класс `Component`, метод `renderVals()`).
- `<sc-for list="{{items}}" as="x">` — повтор блока по списку; `<sc-if value="{{flag}}">` — условный показ.
- `<dc-import name="ConfigDesktop" preset="many">` — вставка другого артборда (компонента) с пресетом состояния.
- `support.js` из шапки файлов — рантайм редактора. Он не нужен: файлы — справочник, а не код для сайта.
- Пути к картинкам уже заменены на `/img/…` и `/logo/…` из `public/`.

## Интерактивные артборды

- `ConfigDesktop`, `ConfigMobile` — калькулятор. Логика расчёта описана в `renderVals()`, данные вынесены в `data/configurator.json`.
- `Portfolio`, `PortfolioMobile` — фильтры по услуге и марке, «Показать ещё».
- `NavMobile` — аккордеон направлений.
- `Service*` — FAQ-аккордеон.
