Сверстай сайт студии «Космос Wrap × Апгрейд Garage» по макету из этой папки.

Сначала прочитай `CLAUDE.md`, потом `docs/spec.md`, `design/README.md` и `data/*.json`. Исходники экранов — `design/*.dc.html`: бери из них точные размеры, отступы, цвета и тексты. Тексты страниц услуг — `docs/seo-texts.md`.

Порядок работы:

1. Инициализируй проект на Astro + TypeScript с островками на Preact. Подключи шрифты Unbounded и Manrope через @fontsource, токены из `data/tokens.css`.
2. Собери базовые компоненты по `UIKit` и `States`: кнопки, CallButton, теги, карточки, FAQ, тост. Затем шапку (обычная 88px и компактная 64px при прокрутке), мега-меню, мобильное меню, подвал, нижнюю мобильную панель.
3. Главная (`Home`, `HomeTablet`, `HomeMobile`) — на брейкпоинтах 1440 / 768 / 390, между ними — «резиновая».
4. Шаблон страницы услуги (`Service`, `ServicePPF` и мобильные версии). Сгенерируй все 21 страницы из `data/services.json` и `docs/seo-texts.md`. У каждой — свои title, description, H1, FAQ с разметкой schema.org FAQPage, цвет по направлению.
5. Калькулятор — остров на Preact по `ConfigDesktop` / `ConfigMobile` и `data/configurator.json`. Состояние в URL, кнопка «Скопировать ссылку на расчёт». Никаких форм и отправки данных.
6. Портфолио с фильтрами, страница кейса (по `Case`), политика, 404, плашка cookie.
7. SEO: sitemap.xml, robots.txt, Open Graph, schema.org AutoRepair / LocalBusiness с адресом, часами и телефонами из `data/contacts.json`.
8. Яндекс Метрика с целями из `docs/spec.md`. ID счётчика пока заглушка в конфиге.

Требования: форм нет; контраст ≥ 4.5:1; тап-зоны ≥ 44px; `prefers-reduced-motion`; Lighthouse ≥ 90 по всем пунктам на мобайле. Заглушки из раздела «Заглушки» в `CLAUDE.md` оставь как есть и вынеси в данные.

Работай по шагам. После каждого шага запускай сборку и сверяй экран с артбордом. Коротко пиши, что сделано и что дальше.
