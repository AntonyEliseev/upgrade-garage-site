# Космос Wrap × Апгрейд Garage — сайт студии

Сайт московской студии из двух направлений под одним брендом:

- **Космос Wrap** (розовый `#E2609B`) — плёнки и оклейка: антигравийная плёнка, антидождь, матовая статика на экраны, салон по лекалам, карбон, полировка, PDR, смена цвета, антихром, атермальная плёнка, керамика на диски, мотоциклы.
- **Апгрейд Garage** (лайм `#CDE23C`) — шумоизоляция, автозвук и дооснащение: доводчики, привод багажника, магнитолы, ребилд фар, Ambient-подсветка, регистраторы и камеры, омыватель камер.

Язык сайта — русский. Имена компонентов, классов и файлов — на английском.

## Главные правила

1. **Форм на сайте нет.** Никаких полей ввода, заявок и капчи. Связь — только `tel:`-ссылки (Айк и Ксения), Telegram и WhatsApp.
2. **Калькулятор ничего не отправляет.** Выбор хранится в URL (`?body=crossover&z=n_doors,f_hood&pkg=plus`). Кнопка «Скопировать ссылку на расчёт» копирует адрес и показывает тост.
3. **Тёмная тема по умолчанию.** Светлая — через `[data-theme="light"]`, токены в `data/tokens.css`.
4. **Мотив Ambient** — светящиеся линии: розовая слева и лаймовая справа под шапкой, `box-shadow`/`drop-shadow` свечение. При `prefers-reduced-motion` анимации выключены.
5. **Мобильная нижняя панель** (`position: fixed; bottom: 0`) не перекрывает контент: у `body` нижний отступ на её высоту.
6. Контраст текста — не ниже 4.5:1, тап-зоны — от 44×44.

## Стек (рекомендация)

- **Astro** (статическая сборка, SEO, быстрые страницы) + TypeScript.
- Интерактив — островки на **Preact**: калькулятор, фильтры портфолио, мобильное меню, мега-меню. FAQ — на `<details>`.
- Стили — обычный CSS с переменными из `data/tokens.css` (без Tailwind, чтобы токены 1:1 совпадали с макетом).
- Шрифты — `@fontsource-variable/unbounded` и `@fontsource-variable/manrope` (самохостинг, `font-display: swap`).
- Картинки — `astro:assets` (AVIF/WebP, lazy ниже первого экрана).
- Аналитика — Яндекс Метрика, ID пока заглушка. Цели перечислены в `docs/spec.md`.

## Что где лежит

| Путь | Что это |
| --- | --- |
| `design/*.dc.html` | Исходники артбордов макета: вёрстка на инлайн-стилях — источник размеров, отступов, цветов и текстов. `design/README.md` объясняет формат. |
| `design/_index.json` | Список артбордов: название, ширина и высота. |
| `docs/spec.md` | Спецификация: брейкпоинты, сетка, поведение шапки, анимации, аналитика. |
| `docs/seo-texts.md` | Тексты всех 21 страницы услуг: title, description, H1, лид, блоки, FAQ, ключевые запросы. |
| `data/tokens.css`, `data/tokens.json` | Дизайн-токены: цвета тёмной и светлой темы, типографика, отступы, радиусы. |
| `data/services.json` | 21 услуга: название, направление, URL, title, description, H1. |
| `data/configurator.json` | Данные калькулятора: вкладки, кузова, 39 зон (у каждой `dir` — цвет и группа в расчёте), фото вкладок, контуры деталей (`zoneShapes`), оверлей фары, миниатюры зон салона, пакеты и коэффициенты шумоизоляции, цены. |
| `data/portfolio.json` | 19 кейсов (`slug`, `direction`, `cover`, `photos` — до 10 фото) и фильтры портфолио. |
| `data/contacts.json` | Телефоны, мессенджеры, адрес, часы, рейтинг, заглушки реквизитов и даты политики. |
| `data/home.json` | Тексты главной: hero, цифры, карточки работ, «Почему к нам», процесс, отзывы, FAQ. |
| `data/service-pages.json` | Дополнения к шаблону услуги: фото, цифры первого экрана, проблемы, пакеты, вкладка калькулятора, кейсы. |
| `data/cases.json` | Подробные кейсы (`/works/<slug>`) и соответствие фильтров портфолио страницам услуг. |
| `src/assets/img/` | Фото студии и калькулятора; `works/` — галереи кейсов, `zones/` — примеры для карточек зон салона. Оптимизируются через `astro:assets`; в данных пишутся как `/img/…`. |
| `public/logo/`, `public/favicon.svg` | Логотип в векторе и фавикон. |

## Код

| Путь | Что это |
| --- | --- |
| `src/config.ts` | ID Яндекс Метрики (0 — заглушка) и имена целей. |
| `src/lib/calc.ts` | Расчёт калькулятора и состояние в URL. |
| `src/lib/seo.ts` | Разбор `docs/seo-texts.md` для страниц услуг. |
| `src/islands/` | Preact-островки: калькулятор, фильтр портфолио, мега-меню, мобильное меню. |
| `src/components/BeforeAfter.astro`, `Gallery.astro` | Слайдер до/после и галерея кейса с лайтбоксом (без островков, на обычном скрипте). |
| `src/styles/` | `global.css` (токены, кнопки, карточки), `layout.css` (шапка, меню, подвал, панель, cookie), `fonts.css`. |

Команды: `npm run dev`, `npm run build`, `npm run preview`. `npm run check` (astro check) требует Node ≥ 20.

Деплой — GitHub Pages через Actions, см. `docs/deploy.md`. Домен и базовый путь приходят в сборку из `SITE_URL` и `BASE_PATH`, поэтому внутренние ссылки пишем только через `url()` из `src/lib/url.ts`. На `*.github.io` сайт закрыт от индексации.
