# Спецификация для вёрстки

Выгружено из артборда «Спецификация» макета.

## 01. Сетка и брейкпоинты

- Мобайл 390 (до 767), планшет 768 (768–1279), десктоп 1440 (от 1280).
- Колонки 4 / 8 / 12, контейнер до 1280px, поля 16 / 32 / 80, gap 12 / 20 / 24.
- Вёрстка «резиновая» между точками, макеты — опорные ширины.

## 02. Шапка и меню

- Header/Default 88px; после прокрутки на 120px — Header/Compact 64px, полупрозрачный фон + blur 12px.
- MegaMenu/Services открывается по клику и по наведению (задержка 150 мс), закрывается по Esc, клику вне и уходу курсора.
- Мобайл: бургер открывает Menu/Mobile на весь экран, прокрутка страницы под ним блокируется.
- Световая линия под шапкой — две половины, розовая и лаймовая.

## 03. Нижняя панель на мобайле

- MobileActionBar: position fixed, bottom 0, высота 76px + env(safe-area-inset-bottom).
- У body отступ снизу на высоту панели, чтобы она не закрывала контент.
- Скрывается, когда открыто меню или шторка калькулятора; плашка cookie встаёт над ней.

## 04. Связь без форм

- Телефоны — tel:+79855433421 (Айк) и tel:+79858276510 (Ксения), подписи — только имена.
- Telegram — t.me/KosmosWrap и t.me/UpgradeGarage, WhatsApp — wa.me/[номер].
- Форм, полей ввода и капчи на сайте нет.

## 05. Конфигуратор

- Данные — JSON: кузова × зоны × пакеты → цена «от» и срок. В макете — ориентир рынка Москвы: цена зоны × коэффициент кузова (седан 1, кроссовер 1,15, внедорожник 1,3). Итоговую таблицу даёт студия.
- Одно фото модели на вкладку; координаты точек в % от фото, чтобы работали на всех ширинах.
- Выбор хранится в адресе (?body=crossover&z=n_doors,f_hood). Кнопка «Скопировать ссылку на расчёт» копирует адрес, Toast «Ссылка скопирована».
- Расчёт показывается только на странице: в мессенджеры и буфер текст расчёта не уходит.
- Итог — сумма «от», срок — максимум по выбранным позициям. Мобайл: итог в нижней шторке.

## 06. Анимации

- Все переходы 180 мс ease-out; hover только на устройствах с мышью (@media (hover: hover)).
- Световая линия в hero «прорисовывается» при загрузке: stroke-dashoffset, 1.2 с, один раз.
- Скелетоны при подгрузке работ — перелив 1.4 с. Крутилка на кнопке — 0.9 с.
- prefers-reduced-motion: анимации отключаются, свечение остаётся статичным.

## 07. Изображения и карта

- Фото — AVIF/WebP с запасным JPEG, lazy loading ниже первого экрана, фиксированные пропорции карточек.
- Hero — фото или короткий видео-луп без звука (до 3 МБ, постер-кадр).
- Яндекс Карта грузится, только когда пользователь долистал до контактов; при ошибке — MapFallback.

## 08. Шрифты

- Unbounded 500–800 и Manrope 400–800, только кириллица + латиница, font-display: swap.
- Запасные: system-ui, sans-serif. Цифры в ценах — Unbounded, tabular-nums.

## 09. Аналитика

- Яндекс Метрика, цели: клик по телефону, по Telegram и WhatsApp, открытие калькулятора, «Скопировать ссылку на расчёт», «Связаться с мастером».
- Отдельно отслеживать, с какой страницы услуги был звонок.

## 10. Что ещё даёт студия

- Фото для калькулятора можно заменить на студийный кадр кроссовера — точки зон задаются в % от фото.
- Номер для WhatsApp.
- Реквизиты оператора и e-mail для обращений — пока заглушки.
- Сверка цен и сроков: в макете и SEO-текстах стоит ориентир рынка Москвы.
- Фото для кейсов без снимков: Hyundai Accent, Geely Monjaro.

## 11. Страницы

- Главная, 21 страница услуг из шаблона ServicePage (цвет по направлению), портфолио, кейсы, калькулятор, политика, 404.
- У каждой услуги — свой адрес, title и description под поисковый запрос.
